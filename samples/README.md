# 한국어 가상 샘플 사용법

개인정보 탐지와 가림을 시험하기 위한 가상 자료다. 먼저 `한국어/텍스트/00_전체규칙_통합시연.txt`를 복사해 입력하거나 글자판 문서를 하나 올린다. 모두 생성한 시험 정보이며 실제 연락·인증·결제에 사용하지 않는다.

| 폴더 | 내용 | 용도 |
|---|---|---|
| `한국어/가짜 샘플(이미지X)` | 글자 선택이 가능한 문서 20개, 총 21쪽 | 기본 탐지·위치 추출 시험 |
| `한국어/가짜 샘플(이미지O)` | 이미지 문서 8개와 대응 이미지 8개 | 글자 인식 및 흐린 스캔 비교 |
| `한국어/텍스트` | 일반 본문 20개, 이미지판 본문 4개, 통합 시연 1개 | 붙여넣기 시험 |
| `한국어/정답` | 수동 정답, 이미지 좌표, 코드 관측값, 경계 사례 | 결과 비교 |

## 글자판 상황

| 번호 | 상황 |
|---|---|
| 01~06 | 입사 등록, 비상 연락망, 출장비 정산, 거래처 등록, 교육 신청, 고객 문의 |
| 07~12 | 학생 정보, 체험학습 동의, 장학금, 상담 예약, 동아리, 기숙사 |
| 13~16 | 배송 요청, 대관, 진료 예약, 숙박 결제 |
| 17~20 | 카드 검증, 입력값 경계, 반복·두 페이지, 탐지 대상 없음 |

이미지판은 세대 구성표·이름 순위표·전화번호부·심사 결과 안내문 각 두 판이다. 선명판으로 먼저 시험한 후 같은 내용의 흐린스캔판과 비교한다. 일부 마스킹된 전화번호와 일반 숫자는 보존 대상이다.

현재 코드가 지원하는 범위와 한계는 [탐지 기준](../docs/rules.md)을 따른다. 이미지판은 글자 인식 기능을 별도로 요구한다. 수동 정답과 현재 코드의 관측값은 의미가 다르므로 서로 바꾸어 사용하지 않는다. 다국어 자료와 원본 참고 이미지는 포함하지 않았다.
