# 서비스 화면의 스캔 PDF 검증 (#40)

## 실행

`npm run build` 후 `npm run preview -- --host 127.0.0.1 --port 4189 --strictPort`를 실행하고 브라우저에서 `http://localhost:4189/`를 연다. 개인으로 사용하기로 진입한다. 실제 개인정보 대신 저장소의 가짜 샘플만 사용한다.

## 확인한 흐름

- 이미지가 있는 가짜 심사 결과 안내문을 PDF 첨부로 선택하고 개인정보 찾기를 실행했다. 기존 스캔 미지원 오류 대신 모델이 실행됐고, 글자 인식 단계와 처리 취소 버튼이 표시됐다.
- 이름·주민등록번호·전화번호·이메일·주소 각 1건을 찾았다. 개인 항목 선택과 가림 미리보기, PDF 내려받기 버튼을 확인했다.
- 내려받은 파일을 별도로 렌더링해 5곳이 검게 가려진 것을 확인했다. 내려받은 파일의 텍스트 추출 결과는 0글자였다.
- 이미지 없는 가짜 거래처 담당자 등록서도 첨부해 기존과 같은 전화번호·이메일 2건을 확인했다.
- 다시 스캔 문서를 실행하고 처리 취소를 눌렀다. 취소 안내와 비활성화된 내려받기를 확인했다. 브라우저 경고·오류는 없었다.

혼합 문서 합치기, 회전 좌표 환산, 모델 실패 전파, 빈 결과 거부와 취소 신호 전달은 `src/lib/pdf/service.test.ts`에서 검증한다. 전체 검토에서는 실제 글자 1쪽과 90도 회전 스캔 1쪽을 합친 문서에서도 총 7건, 취소 후 재실행, 두 쪽의 가림 위치와 내려받은 파일의 텍스트·주석 0개를 확인했다. 기업 계정의 실제 통계 저장과 운영 주소 재검증은 아직 남아 있다. 이미지 파일 직접 첨부는 이번 PDF 연결 범위에 포함하지 않는다.
