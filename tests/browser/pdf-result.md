# 개인 모드 PDF 화면 확인

`npm run dev`로 앱을 실행한 뒤 아래 순서로 확인한다. 샘플은 모두 저장소의 가짜 정보만 사용한다.

1. 글을 입력하고 `samples/한국어/가짜 샘플(이미지X)/01_신규_입사자_인사등록서.pdf`를 첨부한다. 파일명·쪽수·크기가 표시되고 텍스트 입력창이 비활성화되는지 확인한다.
2. 첨부를 제거하면 이전 글과 입력 기능이 복구되는지 확인한다. 다시 첨부한 뒤 개인정보 찾기를 누르면 글 대신 PDF 결과가 나와야 한다.
3. 왼쪽의 개별 체크와 종류별 번호를 눌러 선택 건수와 검은 가림 영역이 함께 바뀌는지 확인한다. 접기·펼치기는 선택 상태를 바꾸지 않아야 한다.
4. 미리보기 생성 중에는 이전 결과가 노출되지 않고 내려받기 버튼이 비활성화되어야 한다. 빠르게 선택을 바꿔도 마지막 선택만 반영되어야 한다.
5. 내려받은 PDF를 열어 미리보기와 같은 모습인지, 선택한 개인정보가 가려지고 원문 텍스트가 복사되지 않는지 확인한다. 회전된 페이지와 여러 쪽에서도 쪽 번호를 확인한다.
6. 처음부터 다시를 누르면 첨부와 글이 없는 입력 화면으로 돌아가야 한다. 기존 텍스트 탐지·선택·복사도 확인한다.
7. 이미지판 샘플과 손상된 PDF에서는 오류 안내가 나오고 내려받기가 차단되는지 확인한다. 다른 파일은 처음부터 다시를 눌러 첨부한다.
8. 키보드만 사용해 첨부·제거·탐지·개별 및 종류별 선택·접기·내려받기·다시 시작을 조작한다.

자동 검증은 `src/lib/pdf/result.test.ts`에서 실제로 생성한 두 쪽 PDF와 회전 페이지를 읽어 탐지 값·쪽 번호·가림 좌표의 연결을 확인한다. 화면 확인 절차는 자동 검증의 실행 결과를 의미하지 않는다.
