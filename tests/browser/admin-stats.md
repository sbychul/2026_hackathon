# 관리자 통계 화면 검증

대상: 이슈 #38. 피그마 `wmLZEGAtl7EVfMeHc6y0xv`의 데스크톱 `77:197`, 모바일 `79:184`를 기준으로 한다.

사용자와 확인한 범위는 개인정보 7개 규칙의 통계다. 최신 시안의 공통 단어 열과 정책·단어 관리 메뉴는 별도 작업으로 남긴다. 예시 숫자는 실제 통계로 대체하며 조회 실패를 가짜 데이터로 바꾸지 않는다.

## 개발 서버 검사

- `npm run dev`를 실행한다.
- `/tests/browser/admin-stats.html`에서 기존 가짜 통계 함수로 배치를 확인한다. 전체 52건, 사용자 5명, 규칙 7개, 동점 순위 1·1·3·4·5, 0건 사용자와 계좌번호가 표시된다.
- 좁은 화면에서는 요약을 한 카드로 묶고 사용자별 교차표를 펼쳐 읽는다. 키보드로 상세 항목을 열고 닫을 수 있다.
- `/tests/browser/admin-live.html`은 시연 계정으로 실제 조회를 확인하는 개발 전용 화면이다. 계정이나 비밀번호를 코드에 넣지 않는다. 이 경로는 제품 빌드 진입점에 포함되지 않는다.
- 제품의 `/`에서 관리자로 로그인한 뒤 상단의 `통계`를 누른다. 요약·순위·그래프·표와 다시 조회를 확인한다.
- 별도 탭에서 로그아웃하거나 직원으로 로그인하면 제품의 통계 화면이 사라져야 한다. 개발 전용 직접 조회 화면에서는 관리자 전용 안내가 표시돼야 한다.
- 조회 실패에는 오류 안내와 재조회 버튼이 표시되며 기존 수치나 가짜 통계를 노출하면 안 된다.
