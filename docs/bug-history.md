# 버그 이력

- 입력 경로별 실제 처리 대상과 화면 표시 대상이 어긋나는 문제.
- 비동기 브라우저 API 실패를 사용자에게 알리지 않고 처리하지 않는 문제.
- 세션 정리와 입력 상태를 실패 경로에서 누락하는 문제.
- 생략된 룰이나 0건 데이터를 통계·저장 과정에서 잘못 처리하는 문제.
- 시간대 변환을 잘못 적용해 기록 시각이 어긋나는 문제.
- PDF 글자 좌표계를 화면 좌표계와 혼용하는 문제.
- 실패한 PDF 처리에서 페이지·자원을 정리하지 않는 문제.
- 큰 PDF 페이지에서 배율을 과도하게 적용하는 문제.
- 탐지 경계 조건과 표기 변형을 놓치는 문제.
- 겹치는 탐지 구간을 중복 집계하거나 일부만 가리는 문제.
- 이메일 경계가 잘못된 후보의 뒷부분을 부분 탐지하는 문제.
- 사용자 삭제 시 연쇄 데이터 정리와 적용 버전 불일치 문제.
- 이메일 경계와 전화번호 구분자 표기 누락 문제.
- 기존 탐지 룰의 오탐 회귀 검증과 중복 모듈 관리 문제.
