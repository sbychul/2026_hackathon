# 개인정보 가리기

외부에 공유할 글에서 개인정보를 찾아, 선택한 부분을 별표(`*`)로 바꾸는 웹 서비스예요. 자동 탐지가 놓친 내용은 직접 선택해 가릴 수 있어요. 탐지와 가리기는 브라우저 안에서 처리하며, 입력한 원문과 탐지된 실제 값을 서버에 저장하지 않아요.

개인정보를 지우고 글을 공유하려는 개인 사용자, 업무 문서를 공유하기 전에 개인정보를 보호하려는 기업 직원, 보안 교육을 위해 탐지 통계를 확인하려는 관리자를 대상으로 해요.

> **현재 이용 범위**: 2026년 10월 31일 기준 기본 브랜치에서 확인한 기능은 개인 모드의 텍스트 탐지·선택·직접 가리기·결과 복사예요. 실제 배포 주소는 아직 확인되지 않았어요. 기업 모드와 PDF·이미지 처리는 아래 지원 상태를 확인해 주세요.

## 개인 모드와 기업 모드

| 구분 | 개인 모드 | 기업 직원·관리자 모드 |
|---|---|---|
| 현재 화면 제공 상태 | 텍스트 사용 가능 | 로그인·강제 적용·기록 저장·관리자 화면 연결 준비 중 |
| 로그인 | 필요 없어요 | 기업 계정 로그인이 필요한 방식으로 준비 중이에요 |
| 자동 탐지 항목 | 항목별·종류별로 가릴지 선택해요 | 탐지된 항목을 모두 강제로 가리고 해제할 수 없도록 하는 정책이에요 |
| 기록 | 탐지 기록을 저장하지 않아요 | 사용자·시각·탐지 종류·건수·입력 방식만 저장하는 정책이에요 |
| 관리자 열람 | 관리자에게 전송할 탐지 기록이 없어요 | 사람별·종류별 통계만 제공하고 문서 내용이나 탐지된 실제 값은 제공하지 않는 정책이에요 |

상단의 **기업 계정으로 로그인** 버튼은 현재 로그인 화면으로 연결되지 않아요. 지금 제공되는 개인 모드에서 회사의 강제 적용이나 탐지 건수 기록이 이루어진다고 생각하고 사용하지 마세요.

## 개인 모드 사용 순서

### 1. 글을 넣고 개인정보 찾기

1. **개인 모드** 화면의 입력창에 가릴 글을 붙여넣어요.
2. 입력창 아래에서 글자 수를 확인하고 **개인정보 찾기**를 눌러요. 글이 비어 있으면 버튼을 누를 수 없어요.
3. 결과 화면에서 찾은 건수와 **찾은 항목**, **원문**, **가린 결과**를 확인해요.

처음에는 실제 개인정보 대신 [가짜 정보 샘플 안내](samples/README.md)의 텍스트로 사용해 볼 수 있어요.

### 2. 가릴 항목 선택

- 처음에는 자동으로 찾은 항목이 모두 선택되어 있어요. 체크한 항목만 **가린 결과**에서 별표로 바뀌어요.
- **찾은 항목**의 개별 체크를 켜거나 꺼서 가릴 항목을 정해요. 체크를 끄면 해당 원문이 결과에 남아요.
- 종류 이름 옆의 **번호 버튼**을 누르면 그 종류 전체를 선택하거나 해제할 수 있어요. 화살표는 목록을 접고 펼치는 버튼이에요.
- **선택 건수 / 전체 건수**와 **가린 결과**를 함께 확인해요. 이 건수는 자동 탐지 항목 기준이며 직접 가린 부분은 별도로 표시돼요.

### 3. 놓친 부분 직접 가리기

1. **원문** 칸에서 추가로 가릴 글자를 드래그해 선택해요.
2. 원문 위의 **선택한 부분 가리기**를 눌러요.
3. **직접 가린 부분** 목록에 추가되고, **가린 결과**에도 별표로 반영돼요.
4. 잘못 추가했다면 해당 목록의 **취소**를 눌러요. 같은 부분이 자동 탐지에서 계속 선택되어 있거나 다른 직접 가리기 구간과 겹치면 여전히 가려질 수 있어요.

**개인정보를 찾지 못했어요**가 나와도 개인정보가 없다는 뜻은 아니에요. 원문을 확인하고 필요한 부분을 직접 가려 주세요.

### 4. 결과 확인하고 복사

1. **가린 결과** 전체를 읽고 필요한 내용이 모두 가려졌는지 확인해요. 원문 칸과 찾은 항목 목록에는 실제 값이 계속 보이므로 공유할 내용은 결과 칸에서 확인해 주세요.
2. **가린 결과 복사**를 눌러요. 성공하면 버튼이 잠시 **복사했어요**로 바뀌어요.
3. 공유할 곳에 붙여넣고 가림 상태를 한 번 더 확인해요. 원본 문서나 기존 파일 자체가 수정되는 것은 아니에요.

**복사하지 못했어요**가 표시되면 브라우저의 클립보드 권한을 확인하거나 **가린 결과** 칸의 글을 직접 선택해 복사해 주세요. 새 글을 처리하려면 **처음부터 다시**를 눌러 빈 입력 화면으로 돌아가요.

## PDF·스캔 PDF·이미지 지원 상태

현재 서비스 화면에서 사용할 수 있는 범위예요. 파일 선택이 된다는 것과 탐지·가림·내려받기가 된다는 것은 달라요.

| 입력 | 현재 화면에서 가능한 작업 | 현재 제공되지 않는 작업 |
|---|---|---|
| 직접 입력한 텍스트 | 탐지, 항목 선택, 직접 가리기, 결과 복사 | PDF 파일로 내려받기 |
| 글자를 선택할 수 있는 PDF | **PDF 첨부** 또는 입력창에 파일을 끌어다 놓아 파일명 확인 | PDF 탐지, 페이지 미리보기, 영역 선택, 가림 결과 확인, PDF 내려받기 |
| 스캔 PDF·글자와 이미지가 섞인 PDF | PDF 파일 선택만 가능 | 이미지 속 글자 인식과 가림·내려받기 |
| 이미지 파일 | 지원하지 않아요 | 이미지 첨부, 글자 인식, 가림·내려받기 |

PDF를 고르면 입력한 글이 비워지고 **개인정보 찾기** 버튼이 비활성화돼요. 현재는 **PDF 내려받기**까지 진행할 수 없어요. 글자 추출·이미지화 저장 모듈이 있더라도 서비스 화면의 지원이 완료된 것은 아니에요.

PDF 결과 화면, 사각형 직접 가리기, 스캔 PDF·이미지의 브라우저 내부 글자 인식 연결이 완료되면 실제 화면과 확인된 지원 형식에 맞춰 이 안내를 갱신해요. 현재 글자 인식 정확도나 처리 속도를 보장하는 수치는 없어요.

## 어떤 개인정보를 찾나요?

정해진 글자 형식으로 일곱 종류를 찾아요. 실제 인물·계좌의 존재나 문장의 의미를 이해해 개인정보인지 판단하는 기능은 아니에요.

| 종류 | 찾는 형식과 주요 한계 |
|---|---|
| 주민등록번호 | 숫자 6자리-7자리 형식이며 앞 6자리의 월·일을 검사해요. 실제 발급 여부를 확인하지 않으며 하이픈 없는 번호는 대상이 아니에요. |
| 전화번호 | 010·011·016·017·018·019로 시작하는 휴대전화 형식이에요. 하이픈·점·공백 또는 붙여 쓴 형태를 허용하고, 한 번호 안에서 구분자는 같아야 해요. 일반 유선전화·국제전화 형식은 대상이 아니에요. |
| 이메일 | 영문·숫자와 일부 기호로 된 아이디, 점으로 구분된 도메인 형태예요. 큰따옴표로 감싼 아이디, 한글 등 국제화 이메일, 일부 특수기호를 포함한 주소는 누락되거나 일부만 잡힐 수 있어요. |
| 카드번호 | 4자리씩 같은 하이픈 또는 공백으로 구분한 16자리이며 룬 검사값을 통과해야 해요. 붙여 쓴 번호나 다른 자릿수는 대상이 아니며 실제 카드인지 확인하지 않아요. |
| 이름 | `이름`, `성명`, `성함` 라벨 뒤의 한글 2~4자를 찾아 이름 부분만 가려요. 라벨 없는 이름은 찾지 못하며, 라벨 주변의 다른 단어나 인명이 아닌 값이 잘못 잡힐 수 있어요. |
| 주소 | 시·도로 시작하고 도로명과 건물번호 또는 동·리와 번지가 이어지는 형식이에요. 뒤의 숫자 동·호·층도 포함할 수 있어요. 시·도 생략 주소나 아파트 이름 등 자유 형식 상세주소는 놓칠 수 있어요. |
| 계좌번호 | `계좌번호`, `계좌 번호`, `계좌` 라벨 뒤의 숫자·하이픈 묶음에서 숫자가 10~14자리인 번호를 찾아요. 라벨과 은행 이름은 남기며, 라벨 없는 계좌번호나 다른 자릿수는 대상이 아니에요. |

같은 구간이 여러 종류에 해당하면 한 종류로만 표시해요. 예를 들어 계좌 라벨 뒤에 휴대전화 형식 번호가 있으면 전화번호로 분류될 수 있어요. 자동 탐지는 누락과 오탐이 있을 수 있으니 공유 전에 전체 결과를 확인해 주세요.

## 원문과 관리자 통계는 어떻게 다루나요?

현재 개인 모드의 텍스트 탐지와 가리기는 브라우저에서 처리해요. 원문·파일·탐지된 실제 값을 처리 목적으로 서버에 보내거나 탐지 기록으로 저장하지 않아요. **가린 결과 복사**를 누르면 결과가 기기의 클립보드로 복사돼요.

기업 모드는 아직 화면 연결 준비 중이며, 아래는 확정된 데이터 처리 정책이에요.

- 기업 직원과 관리자는 모두 자동 탐지 항목을 강제로 가리는 대상이며 이를 해제할 수 없어요. 자동 탐지가 놓친 부분은 직접 가리기로 추가하는 방식이에요.
- 마스킹 완료 시 자동 탐지의 사용자·시각·종류·건수·입력 방식만 기록해요. 원문, 원본 파일, 탐지된 실제 값은 기록하지 않아요. 0건인 종류와 직접 가린 부분은 탐지 통계에 포함하지 않아요.
- 관리자는 직원 이름과 사람별 탐지 건수 순위, 사람별·종류별 건수 표, 종류별 합계를 보는 방식이에요. 관리자도 원문이나 실제 개인정보 값은 볼 수 없어요. 통계는 보안 교육 대상을 파악하기 위한 것이에요.
- 탐지 건수는 문서 수나 마스킹 실행 횟수와 달라요. 한 문서에 전화번호가 세 개 있으면 전화번호 탐지는 세 건이에요.

기업 로그인 절차·기록 완료 시점·저장 실패 안내·관리자 조회 방법은 실제 연결이 끝난 뒤 화면에 맞춰 추가해요. 현재 개인 화면에서 기업 기록이 저장되거나 관리자 통계를 볼 수 있는 것은 아니에요.

## 개발 관련 안내

개발 환경, 실행 방법과 개발 규칙은 [개발 문서](docs/development.md)를 참고해 주세요. 기능과 데이터 처리 약속은 [기능 명세서](docs/spec.md), 제품의 대상과 방향은 [제품 문서](PRODUCT.md)에 정리되어 있어요. 계획된 기능의 현재 이용 가능 여부는 이 안내의 지원 상태를 확인해 주세요.
